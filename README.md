# 🖍️ Etch A Sketch — HTML, CSS & JavaScript

A browser-based recreation of the nostalgic **Etch A Sketch** toy, built using **HTML**, **CSS**, and **JavaScript**.
## 

🎨 Features

- 🖱️ Mouse-based drawing interaction
- 🎛️ Adjustable grid sizes

💡 Learning Objectives
 - Practice JavaScript DOM manipulation

 - Implement dynamic HTML elements

 - Build responsive UI with minimal code
